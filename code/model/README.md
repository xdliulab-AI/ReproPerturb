# ReproPerturb Model Information

This directory contains relevant information regarding the ReproPerturb approach.

> **⚠️ Code Availability Notice**
> The custom codebase underlying the complete ReproPerturb framework relies on proprietary internal infrastructure and is currently subject to intellectual property and patent protection (Application Number: CN 202610444456.X). 
> 
> Consequently, the complete source code—including the core model architecture, pre-training pipelines, and model checkpoints—cannot be distributed publicly. 

### Independent Replication

While the proprietary source code is restricted, we are committed to scientific transparency. Comprehensive descriptions of the model architecture, implementation parameters, and detailed experimental procedures are provided within the **Methods** and **Supplementary Information** sections of our manuscript. 

These extensive methodological details have been specifically documented to enable researchers to independently replicate the framework's conceptual approach using standard open-source computational tools.

### Repository Context

For releasable core foundational modules, downstream data processing, and related analytical scripts utilized in our study, please navigate back to the root of this GitHub repository and explore the designated analysis directories.
